# Security policy

Security fixes target the latest published Ray360 release. Update to the latest
version before checking whether a reported issue still affects your application.

## Report a vulnerability privately

Use GitHub's [private vulnerability reporting](https://github.com/aasmanbashyal/ray360/security/advisories/new).
Include the affected version, a minimal reproduction, the impact, and any relevant
environment details. Share synthetic or redacted inputs where possible.

Do not put exploit details, credentials, or private media in a public issue.
Ordinary bugs and usage questions belong in the public issue tracker and discussions.

The maintainer will assess the report and coordinate a fix and disclosure through
the private advisory. This project does not offer a bug bounty or a guaranteed
response time. Reports about NumPy, Pillow, a model framework, or a decoder may
need to be coordinated with that dependency's maintainers.
