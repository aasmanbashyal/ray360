# README image credits and reproduction

The three WebP figures in this directory are generated by Ray360 from
**Jordan Pond**, photographed by **Matthew Petroff** and distributed with
[Pannellum](https://github.com/mpetroff/pannellum).

- [Original panorama](https://github.com/mpetroff/pannellum/blob/master/examples/examplepano.jpg)
- [Upstream title and author attribution](https://github.com/mpetroff/pannellum/blob/master/examples/example.htm)
- [Upstream MIT license](https://github.com/mpetroff/pannellum/blob/master/COPYING), retained in [LICENSE-pannellum.txt](LICENSE-pannellum.txt)
- Source SHA-256: `505a9c0093677ab7cd636584bc37672ef3eee4dda2f4f057854e762ed04ffd07`

Changes made for these figures: resizing, projection with Ray360, geometry
outlines, panel arrangement, and explanatory labels. The boxes are illustrative
inputs, not detector predictions or ground-truth annotations. The cube panel is a
display grid, not an atlas format returned by the library. The original photo is
kept in the ignored test cache; only the smaller derived figures are committed.

To regenerate from the repository root:

```bash
uv sync --locked --group dev --extra image
uv run --no-sync python scripts/fetch_test_data.py
uv run --no-sync python examples/readme_gallery.py
```

The generator verifies the source checksum and overwrites only its three named
figure files. Font appearance may vary by platform.
